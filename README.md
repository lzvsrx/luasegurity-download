# Luasegurity — distribuição pública

Criador e marca dona do aplicativo: **lzworldstech**.

Página estática e APK experimental do Luasegurity 1.2.0, hospedados no GitHub Pages:

**https://lzvsrx.github.io/luasegurity-download/**

O código Android é mantido em repositório privado. Este repositório contém apenas o site, a identidade visual, o APK destinado ao download e a licença dos indicadores públicos ESET incorporados. Não contém credenciais ou inventário do aparelho usado nos testes.

## Publicação

GitHub Pages publica a raiz da branch `main`. `.nojekyll` permite servir os arquivos estáticos diretamente. Não há servidor de aplicação, scripts, serviços de terceiros ou ferramentas de análise de visitas adicionados ao site.

Para atualizar o aplicativo, substitua o APK em `downloads/`, recalcule seu SHA-256 e atualize `downloads/SHA256SUMS.txt`, o hash e a versão no HTML. Não publique credenciais ou dados de aparelhos.

## Limites

O APK é de desenvolvimento e a versão é experimental. A IA é simbólica, com regras fixas; não é um modelo generativo. A base inicial possui 31 hashes e pode receber revisões assinadas. Não há garantia de detectar todos os vírus, de ser a solução mais segura do mundo ou de funcionar em todos os modelos. A integração entre apps depende das permissões e interfaces do Android.

Os indicadores ESET acompanham o APK sob BSD-2-Clause; a licença também está em `downloads/ESET-LICENSE.txt`. O projeto não é afiliado à ESET.
